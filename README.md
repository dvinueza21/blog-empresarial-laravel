# Blog Empresarial (Laravel)

Proyecto de blog empresarial desarrollado con Laravel.

## Funcionalidades
- Home público con diseño moderno
- Formulario de contacto
- Dashboard con autenticación (Laravel Breeze)
- Gestión de mensajes
- Gestión y descarga de currículums (CVs)
- Descarga pública del último CV

## Instalación
```bash
composer install
npm install
npm run dev
php artisan migrate
